# 云梭 WMS V1.0 部署运维手册（两阶段部署 · 第一阶段：单体）

> 依据《WMS开发计划》3.7 M7 交付物：生产环境部署包与运维手册。
> 形态：单体 `wms-admin`（Nginx + MySQL8 主备 + Redis）。第二阶段微服务化拆分（asrs/sync/message-gateway）列入 M8+。

## 1. 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 1.8 | RedHat OpenJDK 1.8.0 验证通过 |
| MySQL | 8.0 | 主备半同步复制；utf8mb4 |
| Redis | 6.x | 登录态/验证码/缓存 |
| Nginx | 1.20+ | 静态资源 + 反代，见 `nginx.conf.example` |
| 构建工具 | Maven 3.9 | 离线仓库 `.tools/m2-repository` |

## 2. 构建与部署包

```bash
# 后端（离线仓库）
cd wms
mvn clean package -DskipTests -Dmaven.repo.local=D:/prj/wms/.tools/m2-repository -o
# 产物：wms-admin/target/wms-admin.jar

# 前端
cd wms-ui
npm run build:prod
# 产物：dist/ → 部署至 /opt/wms/wms-ui-dist
```

部署目录规划：

```
/opt/wms/
├── app/wms-admin.jar            # 后端单体
├── app/application-prod.yml     # 生产配置（外部化，见 §3）
├── wms-ui-dist/                 # 前端静态资源
├── nginx/nginx.conf.example     # 反代配置
├── sql/                         # 初始化与增量脚本（§4）
├── logs/                        # 应用日志
└── backup/                      # 数据库备份
```

## 3. 配置要点（application-prod.yml）

- 数据源：指向 MySQL 主库（备库只读容灾），连接池按 4C8G 建议 50。
- Redis：生产实例 + 密码；验证码/登录态依赖 Redis，主从切换需容忍短暂重登。
- 日志：按天滚动，保留 30 天；JVM 崩溃日志（hs_err_pid*）目录单独收口。
- 定时任务：同步补偿 Job 随应用启动（`wms-service-sync` 的 `@Scheduled`，30s 轮询），多实例部署时**只允许一个实例启用**（当前单体形态天然满足）。

## 4. 数据库初始化与增量（按里程碑顺序执行）

1. 全新库：执行项目根 `wms_table_design.sql`（43 表全量）。
2. 存量库增量：
   - `wms/script/sql/wms_m5_init.sql`（M5 库内管理：两表 ALTER + 菜单/编号/字段配置）
   - `wms/script/sql/wms_m6_init.sql`（M6：sys_field_config 三列 + asrs_scan_log + 移动列示例）
   - `wms/script/sql/wms_m7_init.sql`（M7：sync_record + 同步对账菜单/字段配置 + SYNC_RETRY 设置）
3. 备份策略：每日全备（mysqldump/xtrabackup）+ binlog 增量；主备校验每周。

## 5. 单据打印服务接入（sys_print_template 驱动）

- 打印模板维护：系统管理 → 打印模板（PRINT_TEMPLATE，M2 上线），模板内容占位符按单据字段。
- 前端打印入口：单据表单/列表按钮位经 `getPrintButton(functionName)` 读取已配置模板（`/system/print/config/{functionName}`）。
- 打印执行：浏览器端套打（模板渲染 → 浏览器打印）；如需静默打印/网络打印机，部署打印客户端（Nginx `location /print/` 反代样例已预留），客户端从 `sys_print_template` 拉取模板并接收打印任务。

## 6. 上线检查清单（第一阶段）

- [ ] `wms_table_design.sql` + 三个里程碑增量脚本执行完毕
- [ ] 系统设置存在 `SYNC_RETRY`（自动重试次数/间隔，Q1 可配置）
- [ ] 登录/权限树/菜单过滤正常（M1 基线回归）
- [ ] 全部 26+2 个 PC 列表模块分页/列设置/查询可用（M2 引擎回归）
- [ ] 终端入口可达：`/terminal/scan`、`/pda`（免登白名单）
- [ ] sync_record 随单据生效写入；补偿 Job 日志可见（"同步补偿任务：本轮到期 N 条"）
- [ ] 对账报表可打开（同步监控 → 对账报表菜单）
- [ ] Nginx 反代/回退路由/上传大小（100m，Excel 导入）验证

## 7. 日常运维

| 事项 | 命令/位置 | 说明 |
|---|---|---|
| 启停 | `systemctl start/stop wms-admin` | 建议注册 systemd 单元 |
| 应用日志 | `/opt/wms/logs/` | 同步补偿关键字：`同步补偿` |
| 同步监控 | PC 菜单 → 同步对账 → 同步监控 | 未同步/失败记录人工重推（表单页"重发同步"按钮） |
| 对账 | PC 菜单 → 同步对账 → 对账报表 | 差异批次展开定位单据 |
| 重试配置 | 系统管理 → 系统设置 → `SYNC_RETRY` | content JSON：`{"maxRetry":5,"baseIntervalSec":60}` |
| 应急 | 重推不成功 → 核对 ERP 侧校验项（erp_doc_no 等）→ 修正后人工重推 | 幂等键保证不重复回写 |
